# 🏥 Hospital Website

A responsive, user-friendly website designed for a healthcare facility to showcase hospital services, medical specialties, doctor profiles, and facility tours.

🌐 **[Live Demo](https://owaisi-hospital-website.pages.dev/)**

---

## ✨ Features

- **🩺 Medical Specialties & Services:** Detailed information about departments, treatments, and clinical care.
- **🏛️ Virtual Facility Tour:** Interactive photo gallery showcasing hospital infrastructure and patient wards.
- **📱 Responsive UI:** Seamlessly adapted for mobile phones, tablets, and desktop screens.
- **📞 Contact & Emergency Info:** Quick access to hospital contact details, emergency helpline, and location.

---

## 🛠️ Built With

- **HTML5** – Semantic structure and content
- **CSS3** – Custom styling, modern layouts, and animations
- **JavaScript (ES6)** – Interactive elements and photo tour logic
- **GitHub Pages** – Live deployment and hosting

---


## 🚀 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/syedaarishmehdii-ui/<Owaisi-Hospital-Website>.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd <Owaisi-Hospital-Website>
   ```
3. **Open `index.html`:**
   Double-click `index.html` or open it with the **Live Server** extension in VS Code.
